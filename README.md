# dciancu Services

## How do I install these formulae?

`brew install dciancu/services/<formula>`

Or `brew tap dciancu/services` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "dciancu/services"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
